developer website lives on this domain, including those under a path:

- OutGym Finder: https://jivkojelev91.github.io/outgym-finder/ (repo `outgym-finder`)
- Crocobu: https://jivkojelev91.github.io/crocobu-site/ (repo `crocobu-site`)
